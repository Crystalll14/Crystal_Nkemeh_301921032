## 1. Project Overview

This repository contains my individual practical portfolio for MIT 8103 – Advanced Database Systems.

The project focuses on designing, implementing, and evaluating an advanced database system for PurpleBank. PurpleBank is a simulated Nigerian digital banking platform that allows customers to create accounts, deposit and withdraw funds, transfer money, and view transaction histories.

The portfolio demonstrates how database technologies can support digital banking operations through efficient data management, transaction processing, query optimisation, concurrency control, NoSQL integration, and distributed database architecture.

### Business Description

PurpleBank is a fictional Nigerian digital bank that provides customers with digital financial services, including account management, fund transfers, deposits, withdrawals, and transaction history tracking.

The proposed database system will support the secure storage, retrieval, and management of financial information while maintaining transaction integrity, data consistency, and system reliability.

## 3. Portfolio Activities

### Portfolio 1: Database Design and Modelling
Design a relational database for PurpleBank, including entity-relationship diagrams, relational schemas, primary and foreign keys, constraints, and normalisation.

### Portfolio 2: Query Processing and Optimisation
Develop SQL queries to retrieve and analyse banking records. Investigate indexing strategies, execution plans, and query performance improvements.

### Portfolio 3: Transactions and Concurrency
Implement transaction management using COMMIT, ROLLBACK, isolation levels, and concurrency control mechanisms to demonstrate reliable financial operations.

### Portfolio 4: NoSQL and Advanced Data Models
Design a NoSQL model for selected PurpleBank data and examine its suitability for handling banking-related information.

### Portfolio 5: Distributed and Cloud Database Exercise
Explore distributed database concepts for PurpleBank, including replication, availability, consistency, and cloud database deployment considerations.
